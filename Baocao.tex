Trong thời đại học tập trực tuyến ngày càng phổ biến, nhu cầu về công
cụ giao tiếp tích hợp hỗ trợ AI không ngừng tăng cao. Các nền tảng hiện
có như Zalo hay Microsoft Teams đáp ứng được giao tiếp cơ bản nhưng chưa
kết hợp sâu với trợ lý AI trong môi trường học thuật.

Xuất phát từ thực tiễn đó, nhóm 18 xây dựng \textbf{StudyFX Chat} --
ứng dụng chat desktop dành cho sinh viên, kết hợp \textit{trò chuyện
nhóm thời gian thực} và \textit{trợ lý trí tuệ nhân tạo tích hợp}. Đây
đồng thời là dự án thực hành vận dụng toàn diện kiến thức học phần
\textbf{IT3103 -- Lập trình Hướng đối tượng}.

\subsection{Cơ chế Auto-Discovery Server}

\begin{tcolorbox}[infostyle, title={Quy trình khởi động tự động (UDP Auto-Discovery)}]
\begin{enumerate}[leftmargin=1.8em, itemsep=5pt]
  \item \textbf{Broadcast UDP:} \code{ServerDiscovery.discoverServer()} phát
    gói tin \code{STUDYFX\_DISCOVER} lên cổng UDP 1236 tới toàn bộ LAN
    (\code{255.255.255.255} và các subnet broadcast).

  \item \textbf{Nếu tìm thấy server đang chạy:} Server phản hồi với IP và cổng
    TCP. Ứng dụng hiện tại chuyển sang \textit{chế độ Client} và kết nối vào.

  \item \textbf{Nếu không tìm thấy:} Ứng dụng khởi động \code{Server} TCP (cổng
    1235), bật \code{beacon UDP}, rồi tự kết nối vào chính mình với vai trò client.
\end{enumerate}
\vspace{4pt}
\textit{Kết quả: Chạy nhiều instance \code{mvn javafx:run} để chat nhóm mà không
cần khởi động server thủ công.}
\end{tcolorbox}

\section{Thiết kế Cơ sở Dữ liệu và Lưu trữ}

Dữ liệu được quản lý theo ba cơ chế:

\begin{enumerate}[leftmargin=2em, itemsep=6pt]
  \item \textbf{Bộ nhớ trong phiên (In-memory):}
    \code{UserService} dùng \code{ConcurrentHashMap<String, User>}
    lưu tài khoản trong suốt phiên làm việc. An toàn luồng theo thiết kế.

  \item \textbf{File text (\code{chat\_history.txt}):}
    Mỗi tin nhắn ghi một dòng định dạng \code{[yyyy-MM-dd HH:mm:ss] Nội dung}.
    Phương thức \code{saveMessage()} được \code{synchronized}. Tự cắt bớt khi
    vượt 2000 dòng.

  \item \textbf{File cấu hình:}
    \code{config.properties} lưu API key, host/port;
    \code{theme.properties} tại \code{\textasciitilde/.studyfx/} lưu tuỳ chọn giao diện.
\end{enumerate}

            Platform.runLater(() -> {          // Cap nhat UI tren UI Thread

                append("@#$%^01naffajg: " + reply);
            });
        }).start();
    } else {
        socket.sendMessage(displayName + ": " + msg);
    }
}
\end{lstlisting}

Ba cơ chế chính của module này:
\begin{enumerate}[leftmargin=2em, itemsep=4pt]
  \item \textbf{Kết nối có retry:} Thử tối đa 12 lần (cách 500ms) trước khi
    báo lỗi.
  \item \textbf{Hiển thị bong bóng:} CSS class động theo loại tin
    (\code{mess-global} / \code{other-global} / \code{bot-message} /
    \code{join-notification}) kèm FadeIn 300ms.
  \item \textbf{Observer:} Triển khai \code{SocketManager.MessageListener},
    nhận tin qua \code{onMessageReceived()} và chuyển lên UI Thread bằng
    \code{Platform.runLater()}.
\end{enumerate}

  \item \textbf{File đính kèm:} Truyền ảnh và tài liệu qua socket.
\end{itemize}

\section{Bài học Kinh nghiệm}

\begin{tcolorbox}[infostyle, title={Kiến thức OOP đã vận dụng}]
Dự án chứng minh OOP không chỉ là cú pháp \code{class} và \code{extends},
mà là \textit{triết lý thiết kế}:
\begin{itemize}[leftmargin=1.5em, itemsep=4pt, topsep=4pt]
  \item Đóng gói xác định ranh giới trách nhiệm giữa các module.
  \item Kế thừa JavaFX Framework -- ví dụ sống động nhất: chỉ cần ghi
    đè đúng phương thức vòng đời, không viết lại event loop.
  \item Đa hình qua interface (\code{MessageListener}) -- ``lập trình theo
    hợp đồng'' giúp mở rộng mà không sửa code cũ.
  \item Singleton, Observer xuất hiện \textit{tự nhiên} khi gặp bài toán
    thực tế, không phải vì cố áp đặt pattern.
\end{itemize}
\end{tcolorbox}

\begin{tcolorbox}[keystyle, title={Kỹ năng nghề nghiệp thu được}]
\begin{description}[leftmargin=0pt, itemsep=5pt]
  \item[\textcolor{hustblue}{Lập trình mạng:}]

  \item[\textcolor{hustblue}{Tích hợp API:}]

  \item[\textcolor{hustblue}{Đa luồng:}]

  \item[\textcolor{hustblue}{Làm việc nhóm:}]

    debug hệ thống tích hợp từ nhiều thành viên.
\end{description}
\end{tcolorbox}
